# AI Attendance App

AI-based attendance management system using **Face Recognition and Voice Recognition**.

## Features
- Teacher and Student Login
- Face ID Registration
- Voice Profile Registration
- Face Recognition Attendance
- Voice Recognition Attendance
- Subject and Student Management
- Attendance Records

## Tech Stack
- Python
- Streamlit
- Supabase
- PostgreSQL
- OpenCV
- Face Recognition
- Resemblyzer
- Scikit-learn
- Pandas
- NumPy

## Run Locally
pip install -r requirements.txt
